## Interceptaciones

| | Diferencia | Regla | Ejemplo del curso |
|---|---|---|---|
| **Acercamiento** (cabeza vs curso deseado) | < 15° | **Deseado – Cabeza – Doble P** | 135 → 145: **115°** |
| | 15–60° | **Deseado – Cabeza – 30°** | 250 → 210: **280°** |
| | 60–90° | **Deseado – Cabeza – hasta 90°** | 330 → 045: **315°** |
| | > 90° | **Ruta pasada**: rumbo opuesto al deseado hasta la cuadra, tiempo, 90° + 90° hacia la cabeza | R180 → curso 210: rumbo **030°** |
| **Alejamiento** (cola vs radial deseado) | < 15° | **Radial deseado – P** | R320 → R330: **340°** |
| | 15–90° | **Radial deseado – 45°** | R120 → R050: **005°** |
| | > 90° | **Ruta pasada**: rumbo = radial deseado hasta la cuadra, 45° hacia la cabeza | rumbo 240 → **195°** |

Acercamiento: curso y radial son **opuestos**. Alejamiento: **coinciden**. Ángulo de corte **≤ 90°**.

Flexibilidad **± 10°**. No estándar: dibujo en espejo. Tramos de **1 min**; crono desde **la cuadra o alas niveladas, lo último**. Paralela sin interceptar a los **30 s** → directo a la estación.

**Cronometraje**: sobra tiempo en el acercamiento → **mitad, se resta**; falta → **doble, se suma**. 1:20 → 50 s · 50 s → 1:20.

## Arco DME

| | Viraje estándar | Medio estándar |
|---|---|---|
| Radial → arco (NM) | **0,5 % GS** | **1 % GS** |
| Arco → radial (°) | **60 × 0,5 % GS / distancia** | **60 × 1 % GS / distancia** |

Se **suma** en acercamiento y se **resta** en alejamiento. Mantener ± **0,5 NM**; tramos rectos **+10° / −5°** respecto de la punta de ala; 0,5 NM dentro → 5° más abajo; 0,5 NM fuera → 10° más arriba.
